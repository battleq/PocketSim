# Show and tell 投稿指南

> [English](show-and-tell-guide.md) · 中文

> 把你用 PocketSim 算过的生活力学案例分享出来，让更多人看到「手机也能算有限元」。
> 优质投稿会被收入 README 案例库，投稿者进入致谢名单。

## 为什么分享

- 帮作者校准求解器的工程边界（真实场景比合成测试更有价值）
- 让其他用户学到「这个场景也能算」
- 有机会被官方账号（B站/小红书）做成视频，署名致谢

## 一个好的 Show and tell 长什么样

### 推荐结构

1. **一句话场景**：「阳台晾衣架挂 3 床湿被子，算一下会不会断」
2. **实物照片**（1–2 张）：让大家看清楚是什么东西、大概尺寸
3. **建模截图**：App 里的模型预览（节点、杆件、支座、载荷）
4. **结果截图**：应力云图 + 安全系数 + 关键数值
5. **一句话结论**：「安全系数 1.8，日常挂没问题；叠 4 床就危险了」
6. **（可选）交叉验证**：手算或其他软件的结果对比，误差多少

### 好例子

> 📌 **「鱼缸玻璃 600×400×8 mm，装满水会裂吗」**
>
> - 场景：家里 60cm 鱼缸，玻璃 8mm 厚，装满水约 96L
> - 建模：底面四边固支，板面受静水压力（线性分布）
> - 结果：最大主应力 18 MPa，安全系数 2.8（钢化玻璃抗弯强度约 50 MPa）
> - 结论：日常使用安全；但如果有硬物撞击边角，应力集中会骤增。

### 不推荐的内容

- 只甩一张结果图，没有场景说明
- 涉及人身安全的严肃工程问题（请找专业工程师，不要靠这个 App 决策）
- 与 PocketSim 无关的内容

## 怎么投稿

1. 进入 Discussions → **Show and tell** 分类
2. 点 **New discussion**
3. 标题格式：`【案例】场景一句话`（如 `【案例】阳台晾衣架挂 3 床湿被子`）
4. 按上面的结构写正文，贴图
5. 加标签（如果有）：`生活案例` / `交叉验证` / `温度` / `风载`

## 被收录进官方案例库的条件

- 场景真实、有照片
- 建模与结果截图清晰
- 结论用大白话，不夸大
- （加分）有手算或其他软件的交叉验证

被收录的投稿者会出现在 README 的「社区贡献」致谢名单中。
