# 欢迎来到 PocketSim 👋

> [English](welcome.md) · 中文

> **PocketSim 口袋仿真**：手机上的 AI + 有限元「生活力学验证器」。
> 拍照 + 一句话，AI 建模算出「晾衣杆会不会断」。所有力学计算在手机本地完成，
> 不上传几何与荷载数据。

这是项目的官方 Discussions 区，欢迎在这里交流、提问、分享算例。

## 维护者说

PocketSim 还很初级：一个不到 70 MB 的安装包，只做得动杆件、实体、容器这类小问题。和成熟的商业仿真软件相比，它只是海里的一滴水。但一滴水从没想跟海比大小——它想做的是把力学校核的门槛降下来：当你不确定晾衣架撑不撑得住、鱼缸玻璃厚不厚时，不该先打开 ANSYS 再学两周有限元，而是拍张照、说句话，答案当场就有。每迭代一个版本，这滴水就多想映出一点海的光。

## 快速上手

1. **下载**：GitHub Releases 页下载最新 APK，安装后授予相机权限。
2. **建模**：首页选场景模板，或直接拍照/描述让 AI 建模。
3. **出结果**：点「开始计算」，本地求解后给出应力、变形、安全系数与通俗结论。
4. **AI 追问**：结果页可继续问「如果挂两倍重呢」，重算不重新建模。

## 免责声明（重要）

本 App 的仿真结果**仅供日常生活参考**，不可用于建筑结构、桥梁、压力容器、
航空航天、特种设备等人身与财产安全相关的专业工程领域。如需严肃工程报告，
请咨询持证工程师或使用专业云服务。

## 隐私说明

- **BYOK 模式**：AI 建模需要你自行填写兼容 OpenAI 的 API Key，图片/文字直接发送
  到你自选的 LLM 服务商，**不经过 PocketSim 的服务器**。
- **本地计算**：所有有限元求解在手机本机完成，不上传几何、材料、荷载数据。
- **不收集数据**：App 不收集、不存储你的模型、图片或 API Key（Key 仅存本机
  DataStore，可随时清除）。
