# 性能基准

> PocketSim 三维实体网格档位的参考基准数据。「为什么超精细比精细慢 9 倍」的实测拆解与优化思路见 [mesh-performance-analysis.zh-CN.md](mesh-performance-analysis.zh-CN.md)。英文版：[performance-benchmarks.md](performance-benchmarks.md)。

## 网格档位

三维实体（墙体、通用箱体/板/圆柱）提供 `coarse / medium / fine / ultra` 四档网格。档位只决定单元数与自由度，与机型无关；耗时随处理器变化，App 结果页会直接显示「网格 · 节点自由度 · 单元 · 求解耗时」。

下表数据为 **x86 CI 沙箱复测**（2026-11-01，Python 3.14.8 / numpy 2.5.3 / scipy 1.18.0 / scikit-fem 11.0.0，单线程），用于验证「fine 与 ultra 差多少」；手机端按 1~3 倍折算。测试与验证机型为 **荣耀 X70**（MTN-AN80，第四代骁龙 6，12 GB + 16 GB 智慧运存，MagicOS 10.0.0.175，2640×1200）。

## 算例与规模

| 档位 | 墙体 3.0×2.5×0.24 m（砖砌体，1200 Pa） | 箱体 1.0×0.2×0.2 m（钢，200 kPa） |
|---|---|---|
| coarse | 7,200 单元 / 5,166 自由度 | 1,152 单元 / 975 自由度 |
| medium | 15,360 / 10,530 | 6,912 / 4,725 |
| fine | 20,160 / 13,770 | 20,736 / 12,987 |
| ultra | 40,320 / 26,442 | 55,296 / 32,487 |

## 耗时（x86 沙箱，组装 / 求解 / 总计）

| 档位 | 墙体 (ms) | 箱体 (ms) |
|---|---|---|
| coarse | 66.8 / 48.3 / 210.2 | 8.4 / 5.1 / 32.2 |
| medium | 209.3 / 210.4 / 719.3 | 64.8 / 62.8 / 281.9 |
| fine | 302.0 / 443.5 / 1,336.6 | 183.9 / 446.4 / 1,411.3 |
| ultra | 726.3 / 1,898.6 / 3,727.7 | 530.3 / 9,594.5 / 15,642.0 |

## 结论

- **fine → ultra**：墙体单元 2.0 倍、自由度 1.92 倍、总耗时 2.79 倍（1.34 s → 3.73 s）；最大应力 0.3977 → 0.3988 MPa（差 0.3%），最大位移 2.02 → 2.07 mm（差 2%）。加密到 ultra 收益有限，**日常估算用 fine 足够**。
- **箱体 ultra 存在耗时跳变**：自由度 32,487 超过 30,000 阈值，自动切到 CG+Jacobi 迭代，求解 0.45 s → 9.6 s（总计 15.6 s）。这属于求解器切换，不是网格本身变慢；箱体/板/圆柱建议保持 medium 或 fine。
- **真机折算**（按 1~3 倍估算）：墙体 fine 约 1.4~4 s、ultra 约 4~11 s；箱体 ultra 约 16~47 s，手机上会明显等待。墙体中/细/超三档的沙箱进程峰值内存为 210 / 265 / 461 MB，远低于 1 GB 预算。
- 复测方法：在 App 里选同一模型，分别用 fine、ultra 出结果，抄录结果页顶部的「网格 · 节点自由度 · 单元 · 求解耗时」即可得到你自己机型的实测数据。
