# 分析能力边界与局限性

> 仅用于教学、DIY 与日常估算，**不可用于正式工程设计**。以下每条均对应 `python/pocketsim/` 的当前实现。
> English version: [limitations.md](limitations.md)。

## 材料本构
- 仅线弹性、小变形（各向同性 E、ν）。
- 不支持：塑性、大变形、接触、摩擦、蠕变、疲劳、各向异性材料。

## 分析类型
- 支持：线弹性静力（2D 框架、3D 梁、2D/3D 实体、MITC4 薄壁壳）、欧拉屈曲校核、准静态温度历程、渗流（达西定律）、流场、埋地管环形变形/屈曲/环向应力（解析公式，非有限元）。
- 不支持：动力时程、模态/频率分析、地震反应谱、非线性屈曲、屈曲特征值、热-力强耦合、流固耦合。

## 截面与几何
- 梁截面仅矩形（实心 / 等壁厚空心）与圆形（实心 / 圆管）。
- 不支持：工字钢 / 角钢 / 槽钢 / 型钢、任意或组合截面、薄壁开口截面、变截面。
- 3D 实体仅长方体 / 圆柱 / 板参数化图元。
- 不支持：开孔、倒角、圆角、多体装配、布尔运算、外部 STEP/STL 导入。
- 杆件开孔仅矩形截面；**圆管 / 圆截面不支持开孔**。

## 单元
- 3D 实体为 4 节点线性四面体（TET4），常应变单元。
- 2D 实体为 6 节点二次三角形（P2）。
- 梁为 Euler–Bernoulli 元（忽略剪切变形），2D 节点 3 自由度、3D 节点 6 自由度。
- 壳为 4 节点 MITC4（Mindlin–Reissner）元，用于等壁厚平底薄壁容器（圆柱料仓 / 矩形水箱），含沿厚度方向应力恢复。
- 不支持：TET10 二次四面体、六面体、膜单元。

## 边界条件
- 仅理想支承：固定 / 铰接 / 滚轴（3D 另支持 `roller_x` / `roller_y`）；实体支持面 / 轮廓 / 点约束。
- 约束必须消除全部 6 个刚体运动模式，否则建模阶段即报错（[L-05] 解析秩预检，无需网格）。
- 不支持：弹性支承、刚性域 / 多点约束（MPC）、预紧力、约束方程、强制位移。

## 载荷
- 支持：集中力、均布压力、自重、静水压力、土压力、风压（风速 / 风级 → q = ½ρv²）、均匀温度变化。
- 量纲换算（kg→Pa、风级→风压、水深→静水压力）由代码完成，AI 只填原始量。
- 不支持：移动载荷、循环 / 动力载荷、热流 / 热对流边界、预应力、初应力、实体集中扭矩。

## 规模与求解
- 2D 框架节点 ≤ 60、杆件 ≤ 80（`MAX_NODES` / `MAX_MEMBERS`）；温度历程时刻数 5–40。
- 2D 实体自由度 ≤ 5 万走直接法（`spsolve`），更大走共轭梯度（CG + Jacobi）。
- 3D 实体自由度阈值 3 万；网格分 `coarse / medium / fine / ultra` 四档（手机上 fine/ultra 可能耗时数秒到十几秒）。
- 求解后校验：位移 nan/inf（奇异 / 欠约束）；最大位移 > 实体对角线一半（机构）；支反力与外载残差 > 5%（报错）；CG 不收敛（降网格档）。
- 不支持：非线性迭代（Newton–Raphson）、特征值求解器。

## 后处理
- 输出：位移（含最大位移节点）、von Mises / 最大主应力、安全系数、反力、云图；框架：杆件内力（轴力 / 剪力 / 弯矩）、挠度曲线、欧拉屈曲校核；薄壁容器：壁面 von Mises 应力、拉/压强度校核。
- 约束边框 / 角点的应力奇异通过仅对内层单元体积加权平均处理，避免云图出现假高应力。
- 不支持：振型 / 动画、主应力迹线、应力线性化（压力容器分类所需的薄膜 / 弯曲应力分离）。

## AI 建模范围
- AI 按结构化 JSON 契约建模，模板限于：框架、空间梁、风压墙体、渗流、温度历程、3D 实体墙体、通用 3D 实体、薄壁容器（壳）。
- AI 用语义锚点（`at = min / max`，坐标由代码解析）定位面，量纲换算交给代码；材料或载荷不清时必须追问，严禁默认。
- AI 输出经过多层校验（结构 schema → 物理语义 → 刚体秩预检）；失败时带"实际值 + 合法取值"的修改单自动重试（结构 1 次、语义 2 次）。
- AI 明确不支持并会追问（`ready = false`）：通用 3D 实体的开孔 / 倒角 / 水平管件，会建议改用梁元模式。
