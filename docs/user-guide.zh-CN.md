# 使用说明

> [English](user-guide.md) · 中文

> **一句话：描述构件 → 检查 AI 建的模型 → 求解 → 读三档结论。**

## 1. 安装与首次启动

1. 从 [Releases](https://github.com/battleq/PocketSim/releases) 下载 APK 安装（Android 8.0+，arm64）。
2. 首次启动会显示免责声明。请读完——它界定了结果能用来做什么、不能用来做什么。
3. 打开**设置**配置 AI 服务商（见第 3 节）。只用场景模板和手动参数的话可以跳过。

## 2. 首页

| 区域 | 作用 |
|---|---|
| **描述你的问题** | 输入一句话，例如"墙上 80 cm 松木搁板，远端放 10 kg 书，会下垂多少？" |
| **AI 建模** | 根据文字和所附照片生成模型 |
| **示例场景** | 现成问题，按*承重结构 / 温度历程 / 风与渗流 / 三维实体 / 薄壁结构 / 埋地管*分类。点一下即填入。 |
| **AI 技能** | 可选预设：*保守校核*（最不利工况、偏保守取值）或*快速估算*（简化模型，先给量级） |
| **模型选择 / 材料定义** | 手动路线：选模板、填参数，不用 AI |
| **拍照** | 给描述附一张或多张照片 |

让拍照建模明显更准的几个习惯：

- 一张照片只拍一个构件。桌面上堆满东西会干扰几何提取。
- 画面里放一个已知尺寸的参照物（尺子、硬币、标准砖），并在文字里说明。
- 用文字写清材料和荷载——"松木"、"10 kg"、"两端焊死"。缺信息时 AI 会估算，但你的数字比它的估算更可靠。

## 3. 配置 AI

**设置 → 厂商预设**会自动填好 Base URL 与模型名，你只需粘贴 API Key。

| 厂商 | 默认 Base URL | 说明 |
|---|---|---|
| Kimi | `https://api.moonshot.cn/v1` | 始终思考；用「推理强度」与「高速模式」控制速度 |
| 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | 默认关闭思考以提速度 |
| DeepSeek | `https://api.deepseek.com` | 自动关闭思考 |
| 自定义 | 任意 | OpenAI 的 `/chat/completions` 或 Anthropic 的 `/v1/messages`（含 Claude 中转） |

字段说明：

- **API Base URL** —— 填到接口路径之前即可，`…/v1` 就够，其余由 App 补全；填完整接口地址也接受，会原样使用。
- **模型名** —— 与服务商文档完全一致。
- **视觉模型** —— 仅在消息带图时使用，按厂商分别保存。留空则沿用主模型。
- **建模推理强度** —— 仅 Kimi：`low` 最快，`high` 平衡（默认），`max` 最强但最慢。
- **高速模式** —— 仅 Kimi：切到 `-highspeed` 变体，约快 2–3 倍，token 约 2 倍。
- **请求超时** —— 严格按你设置的秒数，App 不会偷偷延长。
- **首轮候选数量** —— 同一输入生成 1–3 个模型。选 1 最省钱也最快。
- **候选差异控制** —— 过滤掉与基准差异过大的候选。

## 4. 模式

| 模式 | 适用 |
|---|---|
| **通用结构·自动** | 梁杆框架——搁板、支架、货架、导轨、小型机架（节点 ≤60、杆件 ≤80） |
| **三维实体** | 墙体、楼板、玻璃板、箱体、圆柱——面受载的构件 |
| **薄壁容器** | 等壁厚圆柱料仓与矩形水箱 |
| **埋地管** | 土压与车辆荷载下的 PVC 类管道（工程公式，非有限元） |

风载与渗流通过示例列表和 AI 通道进入。

## 5. 建模流程

1. 输入问题，有照片就附上，需要时选一个 AI 技能。
2. 点 **AI 建模**。若关键信息缺失，它会反问而不是猜——简短回答后继续。
3. 进入**模型预览**。按这个顺序检查：
   - **几何** —— 跨度、高度、厚度。差 10 倍是最常见的错误。
   - **支承** —— 那一端真的是固定，还是只是搭在上面？
   - **荷载** —— 大小、方向、作用位置。
   - **材料** —— 弹性模量几乎线性地影响挠度。
4. 发现错误就地修正。字段级修改用追问（"跨度改成 1.2 米"），不必重建。

## 6. 选择候选

「首轮候选数量」大于 1 时，同一输入会给出最多三个模型，每张卡片带线框缩略图。选最贴近实际的那个再进预览；从预览返回会回到选择页，方便对比。

## 7. 读结果

| 元素 | 怎么读 |
|---|---|
| **结论** | *安全 / 接近临界 / 不建议*——基于安全系数的头条判断 |
| **最大位移** | 与实物对照：800 mm 搁板下沉 2 mm 看不出来，20 mm 就明显了 |
| **应力云图** | 看峰值**在哪里**，以及是否落在支承或角点上（应力奇异） |
| **杆件内力** | 每根杆的轴力、剪力、弯矩——想手算选截面就用这个 |
| **网格 / 自由度 / 耗时** | 说明实际算了什么 |

两个习惯能避免大部分误读：

- 正好落在固定端或内凹角点的热点，多半是**应力奇异**，不是真实应力。心里抹平它，别照着设计。
- 换个网格档位结果差很多，说明**没收敛**。先加密再信。

## 8. 追问与重算

**继续追问 / 修改重算**改的是字段，不是整个模型。"荷载翻倍呢？"或"换成铝"会带着这一处改动重算。这比重新描述问题更快、也更可信。

## 9. AI 优化方案

**AI 优化方案**提出结构改动——通常是加支撑、换截面、挪支座——并用求解器逐个验证。

- 给出问题诊断、优化方案、预期效果与编号改动清单。
- 前后对比图中改动处带编号气泡，可拖动旋转、双指缩放。
- **导出效果图 PNG** 保存当前视角。
- 只改荷载或放松原有约束的"方案"会被标记为无效，不会当成优化成果展示。

把它当作启发思路的工具，而不是最终设计。

## 10. 导出

- **导出 PDF 报告** —— 模型、荷载、结果与结论，便于自己存档。
- **分享** —— 分享结果图，自动附加「仅供参考」水印。

## 11. 常见故障

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `HTTP 404 unsupported_endpoint` | 接口路径错误或重复 | Base URL 填到 `/v1`，让 App 补全 |
| `429` / 限流 | 服务商限流 | 重试；候选数降到 1 |
| 请求超时 | 模型慢或照片太大 | 调大超时、减少照片、开高速模式 |
| 发照片时 App 中断 | 大图 base64 上传遇上慢网 | 一次只发一张 |
| 「未知错误」 | 服务商返回了无法解析的内容 | 检查 Key、额度、模型名 |
| 求解前模型被拒 | 缺支承 / 存在刚体位移 | 补齐或修正支承 |
| 位移大得离谱 | 机构，或单位填错 | 先查支承，再查 mm 与 m |

## 12. 需要记住的边界

- 仅线弹性。不支持塑性、接触、大变形、动力学、疲劳。
- 截面仅矩形与圆形，不支持工字钢 / 角钢 / 槽钢 / T 型钢。
- 三维实体用常应变四面体：**弯曲位移会被低估**。梁类构件请用梁模式，或加密网格。
- 不用于认证。见 [limitations.zh-CN.md](limitations.zh-CN.md) 与 [validation.zh-CN.md](validation.zh-CN.md)。
