# 常见问题（FAQ）

> [English](faq.md) · 中文

## 基础

**PocketSim 是什么？**
一个安卓 App：用一句话或一张照片生成有限元模型，在手机本地求解。覆盖梁杆框架、三维实体、薄壁容器、埋地管、温度历程、风载与渗流。

**免费吗？**
App 免费安装。只产生你自己调用大模型接口的费用，付给你选择的服务商。

**支持哪些安卓版本？**
Android 8.0（API 26）及以上，仅 arm64 设备。

**能离线用吗？**
求解可以离线。用 AI 建模需要联网访问你配置的大模型服务商。

**我的数据存在哪？**
模型与设置都留在手机 App 的私有存储里。App 没有服务器，不收集任何数据。只有 AI 建模那一步会把文字和图片直接发给你填了 Key 的服务商。隐私设计见 [why-pocketsim.zh-CN.md](why-pocketsim.zh-CN.md)。

## 为什么是 PocketSim

**这些生活问题为什么不直接问豆包？**
《口袋仿真》经过有限元模型计算，输出结果以图形化展示——应力云图和变形图直接告诉你哪里受力 / 变形最大、最危险；如果发现结构有安全风险，还能制定加固方案，同样用图形化展示。LLM 类模型的输出更接近生活经验，很难准确描述目标的受力 / 变形状态，也给不出这些图形。完整论述见 [why-pocketsim.zh-CN.md](why-pocketsim.zh-CN.md)。

**为什么以前没人把物理仿真做成 App？**
问题不在算力，而在输入。2020 年的一部手机，已经比 1995 年跑碰撞仿真的工作站更快。但物理仿真建模要求人熟练创建 3D 模型、知道怎么配合力学假设做模型简化、明白材料弹性和塑性的区别、知道各向异性材料要设置哪些参数、不同边界条件该简化成什么形式的约束——这对没有专业知识的人太难了。本作品用 AI 解决输入问题：AI 起到人类和物理仿真算法之间沟通的作用，把生活场景和自然语言建成模型，变成仿真算法能明白的输入信息。

## AI 配置

**必须填 API Key 吗？**
做 AI 建模和追问才需要。手动模式（场景模板 + 参数表单）不填也能算。

**支持哪些厂商？**
内置 Kimi、豆包（火山方舟）、DeepSeek 预设，另有**自定义**通道，兼容任意 OpenAI 或 Anthropic 接口（含 Claude 中转站）。选预设会自动填好 Base URL 与模型名，你只需粘贴 Key。

**「API Base URL」到底填什么？**
填到接口路径之前的部分，例如 `https://api.deepseek.com` 或 `https://www.example.com/v1`。App 会自动补 `/chat/completions`；若地址以 `/messages` 结尾、或域名指向 Anthropic，则补 `/v1/messages`。若你直接粘贴完整接口地址，就原样使用，不会重复拼接。

**「视觉模型」填什么？**
发照片时使用的模型。留空则沿用主模型。它**按厂商分别保存**：改 Kimi 的不影响豆包。只有主模型不接受图片时才需要填。

**调接口大概花多少钱？**
取决于服务商和你生成的候选数。设置页「首轮候选数量」可选 1–3，选 1 最省。

**Kimi 感觉慢。**
Kimi 始终开启思考。两个设置能提速：「建模推理强度」选 `low` 最快；「高速模式」会切到 `-highspeed` 模型（约快 2–3 倍，token 约 2 倍）。另外检查「请求超时」——App 不会在你不知情时自动延长。

## 结果

**为什么给三档结论，而不是一个数？**
因为输入本身就是估算。安全系数 2.4 听起来很精确，但荷载有 ±20 %、材料有 ±30 % 的不确定性时，它并不精确。*安全 / 接近临界 / 不建议* 才是数据真正支撑得起的结论。

**为什么和 ANSYS 算的不一样？**
单元形式、网格、边界简化都不同。梁模式与 Euler–Bernoulli 理论完全一致；三维实体用的是常应变四面体，弯曲下比真实情况更刚。测得的误差写在 [validation.zh-CN.md](validation.zh-CN.md)——包括不好看的 TET4 弯曲那一项。

**三维实体算出的位移偏小。**
这是预期内的。常应变四面体在弯曲下低估位移，粗网格可能差几十个百分点。提高网格档位直到数值不再变化，或对梁类构件改用梁模式。

**应力云图可信吗？**
看趋势和峰值位置可以。要拿绝对峰值，先局部加密：粗网格会把应力集中抹平。

## 报错

**`HTTP 404 unsupported_endpoint`。**
接口路径不对，常见是后缀重复（`/chat/completions/chat/completions`），或者中转站只开放 `/v1/messages`。把 Base URL 填到路径之前（如 `https://host/v1`）让 App 补全，或直接粘贴服务商文档上的完整地址。

**限流 / `429`。**
服务商限流。App 会短暂退避后重试一次；仍失败就把候选数降到 1，或稍后再试。

**请求超时。**
调大设置页的「请求超时」，减少照片数量，或换更快的模型。带图的请求比纯文字重得多。

**发照片时 App 直接 abort。**
通常是 base64 大图加上行网速慢。一次只发一张，或用更小的图。

## 适用范围

**能用在实际建筑或承重结构上吗？**
不能。这是教学、DIY 与估算工具，不认证、不复核，不能替代持证工程师。见 App 内免责声明与 [limitations.zh-CN.md](limitations.zh-CN.md)。

**为什么不能建工字钢？**
只实现了矩形与圆形截面。型钢、组合截面、薄壁开口截面均不支持。

**为什么圆管上不能开孔？**
开孔仅支持矩形截面杆件。

**能导入 STEP / STL 吗？**
不能。几何来自参数图元、场景模板或 AI 生成的模型。
