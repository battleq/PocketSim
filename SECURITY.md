# Security Policy / 安全政策

**English**

Please report vulnerabilities **privately** via GitHub's vulnerability reporting:
repository page → **Security** tab → **Report a vulnerability**.
Do **not** open a public issue for security problems.

PocketSim runs entirely on-device; the only external calls are the AI providers
you configure yourself. When reporting anything (including non-security issues),
**never paste API keys, tokens or passwords** — public issues are indexed by
search engines.

Scope: the Android client (`android/`), the solver engine (`python/pocketsim/`)
and this repository's tooling. We aim to acknowledge private reports within
7 days and will discuss disclosure timing with you.

**中文**

请通过 GitHub 的漏洞报告入口**私密**上报安全问题：
仓库页 → **Security** 标签 → **Report a vulnerability**，不要开公开 issue。

PocketSim 全部计算在手机本地完成，仅按你自行配置的 AI 服务商发起网络请求。
上报任何问题时都**不要粘贴 API Key、令牌或密码**——公开 issue 会被搜索引擎收录。

范围：Android 客户端（`android/`）、求解引擎（`python/pocketsim/`）及本仓库工具链。
我们承诺 7 天内响应私密报告，并与你协商披露节奏。
